# LifeShield

**Understand. Detect. Stay Safe.**

LifeShield is a digital-safety awareness platform that helps everyday users recognize phishing attempts, online scams, suspicious links, and privacy risks — explained in plain language.

## Status

🚧 Under active development. This project is being built in phases; see project history for progress.

## Tech Stack

- **Frontend:** React + JavaScript
- **Backend:** Python + FastAPI
- **Database:** SQLite
